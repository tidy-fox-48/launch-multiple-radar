Launch Multiple Radar

Every protocol that records no token yet, ranked by what its launch would be worth — priced from the launches that already happened.

How a row is priced

The snapshot's own tokened protocols set the price. For each category the radar takes the median market-cap / TVL of the protocols in it whose token already trades, and values a pre-token protocol as if it would trade where its launched peers trade. That peer multiple is then adjusted by three figures from the same snapshot: seven-day TVL growth, the years the protocol has run with no token, and the number of chains it runs on. Records that are products of an already-trading token — wrapped and bridged representations, exchange staking products, second versions — and the exchanges themselves are set aside with the trading set, not ranked: their size is the underlying's, not a launch's. No name is special-cased beyond that published separation; every row shows its own four parts, so you can disagree with any of them. An implied value is a claim about a launch that may never happen — the radar ranks farm-worthy attention, not certainties.
